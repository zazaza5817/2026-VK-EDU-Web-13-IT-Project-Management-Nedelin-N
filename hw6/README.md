Оценка риска = Влияние × Вероятность (шкала 1-3)

| Риск | Тип | Влияние | Вероятность | Оценка | Стратегия |

| Низкое доверие между пользователями - арендатор боится отдавать залог незнакомцу, арендодатель боится отдавать инструмент | Внешний | 3 | 3 | 9 | Предотвратить |

## Стратегии реагирования

### Низкое доверие между пользователями (9)

Это основная угроза для C2C платформы - без доверия транзакций не будет вообще. Стратегия - предотвратить через дизайн платформы: верификация профилей по номеру телефона, система рейтингов и отзывов после каждой аренды, залоговый депозит через платформу, история сделок видна другим пользователям. На старте привлекать первых арендодателей вручную и давать им статус "проверенный владелец".

### Срыв сроков MVP (6)

Интеграция с Яндекс.Картами, логика доступности дат и система уведомлений - нетривиальные задачи, которые легко недооценить. Стратегия - смягчить: закладывать коэффициент 1.5 к оценкам на незнакомые задачи. Если не успеваем - сразу сообщать PM и предлагать план B: выкатить без части функционала, добавить в следующем спринте.

### Уход ключевого разработчика (6)

В команде из 5 человек уход одного - потеря 20% ресурса и всех его знаний. Стратегия - предотвратить: регулярные разговоры с PM о загрузке и удовлетворённости, понятный план роста, справедливая компенсация. Параллельно снижать риск концентрации знаний у одного человека: code review обязателен, документация по нетривиальным решениям, каждую зону ответственности знают минимум двое.

### Появление конкурента (6)

Авито или крупный игрок может запустить похожую фичу быстрее и с большей аудиторией. Стратегия - смягчить: как можно быстрее выйти на рынок с MVP и занять нишу, строить лояльность через качество сервиса и верифицированную базу пользователей - это то, что конкурент не скопирует мгновенно.

### Низкая активность арендодателей (6)

Без предложения нет смысла для спроса. Стратегия - предотвратить: на старте привлекать арендодателей вручную через тематические сообщества и группы ремонтников, давать бонусы первым пользователям, упростить процесс размещения объявления до минимума.

### Превышение бюджета на инфраструктуру (4)

Стоимость S3, сервера и API Яндекс.Карт при росте трафика может оказаться выше ожидаемой. Стратегия - смягчить: мониторить расходы с первого дня, поставить алерты на превышение лимитов, на старте использовать минимальные конфигурации.
